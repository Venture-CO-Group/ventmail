Fejlesztők / API

Messages · MIME · batch · SMTP · webhookok replay-jel

Batch küldés egyedi behelyettesítéssel
curl https://api.ventmail.app/v1/messages \
  -H "Authorization: Bearer $KEY" \
  -H "Idempotency-Key: batch-08-31-a" \
  -F channel=transactional \
  -F template=order_confirmation \
  -F 'to=anna@example.com' -F 'to=bela@example.hu' \
  -F 'recipient-variables={"anna@…":{"order":9183},
                        "bela@…":{"order":9184}}' \
  -F 'o:tag=orders' -F 'o:require-tls=true' \
  -F 'v:campaign_ref=aug-orders'

Max 1000 címzett hívásonként. o:deliverytime ütemez, o:testmode naplóz kiküldés nélkül.
