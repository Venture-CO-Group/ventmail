Messages API

Üzenet küldése

POSThttps://api.ventmail.app/v1/messages

Egyetlen üzenetet ad át a küldőmotornak. A kérés a PreSendGate-en megy át (domain-hitelesítés, suppression, consent, kvóta, rate-limit, címkockázat). Az Idempotency-Key fejléc kötelező.

ParaméterTípusLeírás
fromstringFeladó; hitelesített domainről. kötelező
tostring[]Címzettek (max. 50). kötelező
subjectstringTárgy; merge-tagek engedélyezettek.
html / textstringTartalom; vagy template + variables.
tagsstring[]Statisztikához és szűréshez (max. 3).
o:testmodeboolSandbox: nem kézbesít, csak a seed-allowlist címekre.
